# Omega

Two manga readers, built and shipped side by side. Both remain independent apps — this repo is their shared home.

| Folder | What it is | Stack | Live |
| --- | --- | --- | --- |
| `manga-platform` | **OMEGA** — premium glassmorphism manga & manhwa reader aggregating Cooren API + OmegaAPI behind one UI; in-app reader, library/history, SFW-default with 18+ unlock | React 19 · TypeScript · Vite · Tailwind · Framer Motion | https://manga-platform-eight.vercel.app |
| `akari` | **Akari** — minimalist manga & manhwa reader, AniList-curated, warm paper-toned UI, frosted-glass tab dock | Next.js 15 · TypeScript | https://akari-iota-eight.vercel.app |
